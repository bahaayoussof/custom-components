# Momah UI Components

Welcome to the **Momah UI Components** documentation. This site compiles and documents all reusable ASP.NET Core Razor Partial Views (`.cshtml`) and custom JavaScript/CSS components designed for the Momah platform.

## Architecture

Each component is located in its own self-contained directory in the root repository. Each directory holds:
- **Partial View (`_*.cshtml`)**: The Razor layout markup for the component.
- **Documentation Guide (`_*.md`)**: Explains inputs, C# properties, and provides usage code snippets.
- **Visual Previews (`*.png`)**: Screenshots of the component in different styles or states.

## Automatic Tabbed Documentation

To provide a seamless developer experience, this site automatically processes the component files and merges them. For each component, you will find:
1. **Guide Tab**: The rendered markdown documentation with lists of parameters and usage examples.
2. **Source Code Tab**: The actual C# Razor / HTML / JavaScript / CSS code from the component file, complete with syntax highlighting.
